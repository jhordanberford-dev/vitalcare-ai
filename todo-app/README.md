# 📋 TodoFlow - Modern Task Management App\n\nA beautiful, responsive Todo List application with **local storage functionality** built with vanilla JavaScript, HTML, and CSS.\n\n## ✨ Features\n\n### Core Features\n- ✅ **Add Tasks** - Create new tasks with title, due date, and priority\n- 🎯 **Categorize** - Set priority levels (Low, Medium, High)\n- 📅 **Due Dates** - Assign dates to tasks\n- ✓ **Mark Complete** - Check off completed tasks\n- 🗑️ **Delete Tasks** - Remove individual or all tasks\n- 🔍 **Search** - Find tasks by title or description\n\n### Filtering & Sorting\n- 🔽 **Filter Options:**\n  - All Tasks\n  - Pending (incomplete)\n  - Completed\n  - Today's Tasks\n\n- 📊 **Sort Options:**\n  - By Due Date\n  - By Priority\n  - By Name (A-Z)\n\n### Data Management\n- 💾 **Local Storage** - All data saved automatically to browser\n- 📥 **Export** - Download tasks as JSON file\n- 📊 **Statistics** - View total, completed, and pending tasks\n- 🧹 **Clear All** - Remove all tasks at once\n\n### User Experience\n- 📱 **Responsive Design** - Works perfectly on mobile, tablet, and desktop\n- 🎨 **Modern UI** - Clean, minimalist interface\n- ⚡ **Fast** - Instant interactions, no backend needed\n- 🔔 **Notifications** - Feedback for all actions\n- 🎯 **Intuitive** - Easy to use for everyone\n\n## 📁 Project Structure\n\n```\ntodo-app/\n├── index.html              # Main HTML file\n├── css/\n│   ├── styles.css         # Main styles\n│   └── responsive.css     # Mobile responsive styles\n├── js/\n│   ├── storage.js         # Local Storage Manager\n│   └── todo-app.js        # Main App Logic\n└── README.md              # Documentation\n```\n\n## 🚀 Quick Start\n\n1. **Clone or download** the repository\n2. **Open** `index.html` in your browser\n3. **Start** adding tasks!\n\nNo installation, build process, or server required!\n\n## 💻 How to Use\n\n### Adding Tasks\n1. Type task title in the input field\n2. (Optional) Select a due date\n3. (Optional) Set priority level\n4. Click \"Add Task\" or press Enter\n\n### Managing Tasks\n- **Complete**: Check the checkbox next to the task\n- **Edit**: Click the edit icon to modify task details\n- **Delete**: Click the trash icon to remove a task\n- **Search**: Use the search bar to find specific tasks\n\n### Filtering & Sorting\n- Click filter buttons to show specific task categories\n- Use sort buttons to organize tasks by date, priority, or name\n\n### Exporting Data\n- Click \"Export\" button to download all tasks as JSON\n- Perfect for backup or sharing\n\n## 🛠️ Technical Details\n\n### Local Storage Implementation\nAll tasks are automatically saved to browser's local storage:\n```javascript\n// Tasks are stored in localStorage with key 'todoflow_tasks'\nconst tasks = JSON.parse(localStorage.getItem('todoflow_tasks'));\n```\n\n### Task Data Structure\n```javascript\n{\n  id: 1234567890,              // Unique timestamp-based ID\n  title: \"Task title\",          // Task name\n  description: \"Details\",       // Optional description\n  dueDate: \"2024-01-15\",       // ISO date format\n  priority: \"high\",             // low, medium, high\n  completed: false,             // Completion status\n  createdAt: \"ISO timestamp\",  // Creation time\n  updatedAt: \"ISO timestamp\"   // Last update time\n}\n```\n\n### Key Classes\n\n**StorageManager** - Handles all localStorage operations\n- `getTasks()` - Retrieve all tasks\n- `addTask(task)` - Add new task\n- `updateTask(id, updates)` - Update task\n- `deleteTask(id)` - Remove task\n- `toggleTask(id)` - Mark complete/incomplete\n- `exportTasks()` - Download as JSON\n- `getStats()` - Get task statistics\n\n**TodoApp** - Main application logic\n- Manages UI rendering\n- Handles user interactions\n- Filters and sorts tasks\n- Manages modal dialogs\n\n## 🎨 Customization\n\n### Colors\nEdit CSS variables in `styles.css`:\n```css\n:root {\n    --color-primary: #6366f1;        /* Main color */\n    --color-secondary: #10b981;      /* Success color */\n    --color-danger: #ef4444;         /* Danger color */\n    /* ... more colors */\n}\n```\n\n### Storage Key\nChange storage key in `storage.js`:\n```javascript\nSTORAGE_KEY: 'todoflow_tasks'  // Customize here\n```\n\n## 🔒 Browser Compatibility\n\n- ✅ Chrome (latest)\n- ✅ Firefox (latest)\n- ✅ Safari (latest)\n- ✅ Edge (latest)\n- ✅ Mobile browsers\n\n## 💡 Tips & Tricks\n\n1. **Keyboard Shortcut**: Press Enter in task input to add task\n2. **Bulk Export**: Export regularly for backup\n3. **Search Tips**: Search works in both title and description\n4. **Priority Sorting**: Use high priority for urgent tasks\n5. **Today Filter**: Quick access to today's tasks\n\n## 🐛 Known Limitations\n\n- Data stored locally in browser only (not synced across devices)\n- Clearing browser cache will delete all tasks\n- Browser storage limit: ~5-10MB per domain\n- No internet connection required (fully offline)\n\n## 🚀 Future Enhancements\n\nPotential features to add:\n- Cloud sync with cloud database\n- Task categories/tags\n- Recurring tasks\n- Task reminders/notifications\n- Dark mode\n- Multiple task lists\n- Drag & drop reordering\n- Voice input\n- Sharing tasks\n\n## 📝 License\n\nOpen source and free to use!\n\n## 🤝 Contributing\n\nFeel free to fork and improve!\n\n## 📧 Support\n\nFor issues or suggestions, please open an issue in the repository.\n\n---\n\n**Made with ❤️ for productivity lovers**\n\n**Version**: 1.0.0  \n**Last Updated**: 2024\n"
